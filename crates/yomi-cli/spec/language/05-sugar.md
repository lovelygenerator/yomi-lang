# 5. 糖衣の展開

素の行・引用行・選択は、構文解析のあとで、登録済みの停止型コマンドの呼び出しに展開される。コアは、糖衣の種類と引数の形だけを定め、意味（どのコマンドを呼ぶか）は、パッケージやホストが束縛する。

## 5.1 展開の原則

- 糖衣は、3 つの種類（素の行・引用行・選択）に分かれる。
- 各種類は、ホストが登録した**停止型コマンド**に**束縛**される（5.3）。展開したあとの呼び出しが、型検査と実行の対象である。
- 停止型コマンドは、呼ぶと VM が止まる（`Yield`）。ホストが再開の入力を返すと、それがコマンドの戻り値になる。
- 停止点は、停止型コマンドの呼び出しである。安定 ID（`#id`）を付けられるのは、停止型コマンドの呼び出しにあたる行だけ（1.9）。

## 5.2 糖衣の種類と引数の形

| 種類 | 書き方 | 引数 | 戻り値 |
| --- | --- | --- | --- |
| 素の行 | 素の行 | `(text: str)` | なし |
| 引用行 | `identity「…」`、`「…」` | `(identity: Option<Identity>, text: str)` | なし |
| 選択 | `choice { … }`（5.5） | `(options: list<str>, ids: list<Option<str>>)` | `int`（選ばれた番号） |

- `Identity` は、コアの組み込みの型で、`{ id: str, name: str }` を持つ（3.1）。`id` は宣言の名前（`案内人`）、`name` は宣言で与えた表示名（`identity 案内人 = "案内人"` の `"案内人"`）。
- 引用行の `identity` は、identity つきなら宣言に対応する `Identity`、identity なしの引用行（`「…」`）なら `None`。
- 束縛されたコマンドは、この引数の形と戻り値に、型が合っていなければならない。合わなければ、コンパイルエラー。
- `ids` は、`options` と同じ並び・同じ長さで、選択肢の安定 ID を渡す。`#id` のない選択肢は `None`。

## 5.3 束縛

- 束縛は、ホストが、登録表に対して行う（形は host の部で定める）。例：会話を表示するホストは、素の行を `ui.say` に、引用行を `ui.say_as` に、選択を `ui.choose` に束縛する。
- 素の行・引用行・選択は、引数の形が違うので、それぞれ別のコマンドに束縛する。
- 束縛できるのは、停止型コマンドだけである。
- **束縛のない糖衣を台本に書くと、コンパイルエラー**にする。
- ホストが、種類ごとに「無視」を明示的に指定できる。無視された種類の行は、構文と型は検査されるが、コードを生成せず、停止点にもならない（検査だけを行うツールなどのため）。

## 5.4 本文

- 本文（素の行・引用行）は、yomi が解釈せず、文字列として、束縛されたコマンドに渡す。ただし、次の 3 つだけは処理する。
  1. `${式}` を、式の値を文字列にして埋め込む。
  2. 本文のエスケープ（1.10）を解く（`\「` → `「`、`\=` → `=`、`\#` → `#` など）。
  3. 複数行の引用行の、ソース上の改行と、その直後の行頭の半角スペース・タブを取り除く（2.4）。
- ホストが差し替え表（host/05-texts.md）を渡しているときは、安定 ID をキーに、本文（または選択肢の文）を、表の訳文に差し替えてから、束縛されたコマンドに渡す。訳文の中の `${1}` `${2}` は、原文の 1 番目・2 番目の `${式}` の値に置き換える。式は、原文のものを、一度だけ評価する（訳文のために評価し直さない）。差し替えるのは、糖衣の展開で渡す本文だけで、`@` のコマンドの引数は対象にしない。
- ほかのもの（装飾のマークアップなど）は、そのまま文字列として渡す。解釈は、束縛されたコマンドを提供するパッケージが行う。
- 引用行の本文は、書かれた `「` `」` を含めて、そのまま渡す。コアは、括弧を補わず、取り除きもしない。括弧の扱いは、束縛されたコマンドを提供するパッケージが決める。

## 5.5 選択

```ebnf
choice_stmt   = "choice" "{" { choice_option } "}" ;
choice_option = quoted_text [ "once" ] [ "if" expression ] [ stable_id ] "=>" ( block | statement ) ;
```

```
choice {
    「依頼を受ける」 #accept  => { favor += 1; jump quest }
    「断る」         #decline => jump village
    「扉を開ける」 if has_key #open => jump vault
    「掲示板を読む」 once #board => jump board
}
```

- `choice { }` の中の行は、選択の文法で読む（2.1）。
- 選択肢の文（`「…」`）を並べた `list<str>` と、同じ並びの安定 ID の `list<Option<str>>` を、束縛されたコマンドに渡す（5.2）。戻り値の番号の選択肢の文またはブロックを、実行する。
- 選ばれた文を実行し終えたら、`choice` の次の文へ進む（`jump` / `return` / `end` で抜けない場合）。
- 選択肢の文は、書かれた `「` `」` を含めて、そのまま渡す。
- `if` の条件（`bool` の式）は、`choice` に着いたときに、上から順に評価する。偽の選択肢は、渡す `list<str>` に含めない。戻り値の番号は、渡した一覧の中の番号で、VM が元の選択肢に対応づける。
- すべての選択肢が、一覧に含まれないとき（`if` がすべて偽、または `once` がすべて選び済み）は、実行時エラー（`NoChoiceAvailable`）。
- 束縛されたコマンドが、渡した一覧の範囲の外の番号を返したときは、実行時エラー（`ChoiceOutOfRange`）。
- 選択肢の本体は、複数行のブロック（`{ … }` を `}` の行で閉じる）か、1 つの文。1 行に書くブロック `{ 文; 文 }` には、`;` で区切った単純な文（代入・`let`・`jump`・`return`・`end`・`break`・`continue`・コマンド・`call`・素の行）だけを書ける。`if` などの入れ子の文は、複数行のブロックに書く。
- 本体の文には、`choice` を書ける（入れ子）。`choice` は、ブロックの入れ子の深さを 1 段分に数える（`if`・`while` と同じ。6.5 の `block_too_deep`）。
- `choice` は 1 つの停止点である。`choice` の文そのものは、安定 ID を持たない。セーブからの復元では、選択肢の原文から作るハッシュと、ラベルの中の序数で、停止点を見つける（host/04-save.md の 4.4）。選択肢の `#id` は、`ids` として渡され、`once` の状態と `seen`（5.7）の鍵になる。
- `once` を付けた選択肢は、**一度選ばれたら、以降は渡す一覧に含めない**。選ばれたかどうかは、セーブの中の状態（ラベルと安定 ID の組の集合）に持つ（永続データには持たない）。ロールバックで、元に戻る。
- `once` を付けるには、安定 ID（`#id`）が必要。ないときは、コンパイルエラー。
- `once` と `if` は、両方付けられる（`once if 条件 #id`）。両方を満たすときだけ、一覧に含める。
- `once` は、`choice { }` の中の選択肢の文法だけで意味を持つ。予約語にはしない。
- 選択肢が 0 個の `choice` は、エラー。

## 5.6 停止型コマンド

- 停止型コマンドは、副作用型・問い合わせ型（2.2）と並ぶ、コマンドの種類の 1 つである。
- 呼ぶと、VM は `Yield` で止まる。ホストは、再開の入力を返す。入力は、コマンドの戻り値の型に合っていなければならない。
- 停止型コマンドは、糖衣のほか、`@` の文としても呼べる（例：`wait`。戻り値は捨てる）。安定 ID は、行末に付ける（1.9）。
- 待ちは、`yomi-std` の `flow` パッケージが提供する停止型コマンド `flow.wait`（引数 `seconds: float`、戻り値なし）で書く。`import std::flow` のあと、`@flow.wait(1.5) #pause` と書く。安定 ID は、行末に付ける。時間を測るのはホストである（host/01-execution.md の 1.3）。

## 5.7 通過の問い合わせ

台本から、通過したかどうかを調べる、コアの組み込み関数が 2 つある。どちらも問い合わせで、状態を変えない。

| 関数 | 戻り値 | 意味 |
| --- | --- | --- |
| `seen(位置: str)` | `bool` | その停止点を、一度でも通過したか |
| `visited(ラベル: str)` | `bool` | そのラベルに、一度でも入ったか |

- `seen` の `位置` は、`"ラベル名#id"` または `"モジュール名.ラベル名#id"` の形の文字列。モジュール名がないときは、自分のモジュール。安定 ID のない停止点は、調べられない。
- `visited` の `ラベル` は、`"ラベル名"` または `"モジュール名.ラベル名"`。
- 存在しない位置・ラベルを渡したときは、`false`。文字列リテラルで渡したときは、コンパイル時に警告する（位置は `unknown_position`、ラベルは `unknown_label_literal`）。
- `seen` は、**通過済みの停止点**（永続データ。host/04-save.md の 4.5）を読む。安定 ID つきの行に入ったとき（その行の引数を求める前）に記録する。選択肢の `#id` は、その選択肢が選ばれたときに記録する。ロールバックでは、元に戻らない。コアは、通過済みの集合を保持し、永続データ（host/04-save.md の 4.5）として、`persistent var` と一緒に、保存・復元する（`Vm::save_persistent`・`Vm::load_persistent`）。永続データを保存する場所と時機は、ホストが決める。
- `visited` は、**セーブの中の状態**を読む。ロールバックで、元に戻る。ラベルに入るのは、開始・`jump`・`call` のときである。
- 組み込み関数の名前（`seen`・`visited`）は、予約語にしない。同じ名前の宣言は、組み込み関数より優先する（影にする。3.8）。
